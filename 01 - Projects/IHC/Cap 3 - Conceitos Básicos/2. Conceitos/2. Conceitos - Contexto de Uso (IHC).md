# Conceito: Contexto de Uso (IHC)

## Definição

O contexto de uso é caracterizado por toda a situação do usuário que é relevante para sua interação com o sistema. Isso engloba o **momento** (quando) e o **ambiente** (onde)—incluindo aspectos físicos, sociais e culturais.

## Impacto na Interação

O contexto não é apenas o cenário de fundo; ele altera a natureza da interação.

- **Restrições Técnicas:** Um usuário em um desktop tem recursos diferentes (tela grande, mouse) de um usuário em um smartphone no aeroporto (tela pequena, interrupções).
- **Mudança de Objetivo:** O mesmo usuário pode usar o mesmo software para *criar* conteúdo quando está em casa (conforto), mas apenas para *visualizar* quando está em trânsito.

Ignorar as variações do contexto de uso no design pode levar a sistemas inadequados para as situações reais vividas pelos usuários,.
